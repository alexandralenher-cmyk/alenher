# Alexandra Lenher Links

A playful personal link page for Alexandra Lenher, bringing together cats, bikes, nature, creative work, jewelry, social profiles, mountain biking, and favorite products in one mobile-friendly destination.

## Technology

- React
- Vite
- Lucide icons
- Netlify-ready static deployment

## Local development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Create a production bundle with `npm run build`.
